Veebiserver võtab vastu kasutaja HTTP-päringuid ja saadab talle veebilehe faile, rakendusserver töötleb veebilehe loogikat näiteks andmete salvestamist ja kasutaja sisselogimist.

404 Not Found - Server ei leia küsitud lehte või faili.
502 Bad Gateway - Veebiserver ei saa rakendusserverilt korrektset vastust.
